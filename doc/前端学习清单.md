## 第一课：Vue 工程与页面骨架

本课目标：打开浏览器，看到本项目的登录、注册、记账三个占位页，并通过路由切换。页面暂不保存账单、不调用认证接口、不提供真实登录功能；相关功能在后续课次实现。

### 1. 环境与分支

在 Windows 本地 PowerShell 中执行，不是在 Ubuntu 服务器上执行：

```powershell
cd E:\111\expense-tracker
node --version
npm --version
git status --short
git switch -c feat/frontend-shell
```

本次助手环境检查到 Node 24.14.1、npm 11.11.0，学习者终端仍以实际输出为准。当前仓库存在已授权的文档修改，可随新分支保存。分支已存在时切换到该分支，不强制重置。

### 2. 创建前端工程

```powershell
npm create vue@latest frontend
```

工程已创建，此处保留创建流程供复现，不要重新执行创建覆盖现有目录。项目目录为 frontend；实际已启用 TypeScript、Vue Router、Vitest 和 Vue DevTools。后续示例按 .ts 文件组织。脚手架版本不同，可能是逐项问答或多选菜单；多选使用空格选择、回车确认。

然后执行：

```powershell
cd frontend
npm install
npm run dev
```

打开终端输出的 Local 地址，通常是 http://localhost:5173。端口占用时以实际输出为准，不需要使用 --host 暴露开发服务。

理解三个命令：create 创建工程，install 安装依赖，run dev 启动开发服务。Node 运行的是开发/构建工具，最终页面中的 JavaScript 在用户浏览器执行。

### 3. 理解文件结构

```text
frontend/
  index.html             浏览器入口和页面标题
  package.json           依赖和运行命令
  package-lock.json      确定依赖版本，提交 Git
  vite.config.ts         构建工具配置
  src/
    main.ts              创建并挂载 Vue 应用，安装路由
    App.vue              公共外壳与路由展示区域
    router/index.ts      URL 与页面组件的映射
    views/               页面组件
    assets/main.css      全局样式
```

先浏览生成文件，再按以下内容修改。未引用的脚手架示例可以暂时保留；若生成了默认 App 组件测试，按新的页面结构更新或移除只验证演示内容的测试，不保留失效的脚手架断言。

### 4. 替换页面骨架

将 src/App.vue 替换为：

```vue
<script setup lang="ts">
import { RouterLink, RouterView } from 'vue-router'
</script>

<template>
  <header class="site-header">
    <h1>个人记账</h1>
    <nav aria-label="主导航">
      <RouterLink to="/login">登录</RouterLink>
      <RouterLink to="/register">注册</RouterLink>
      <RouterLink to="/transactions">账单</RouterLink>
    </nav>
  </header>
  <main class="page">
    <RouterView />
  </main>
</template>
```

在 src/views/ 下新建三个文件。LoginView.vue：

```vue
<template>
  <section>
    <h2>登录</h2>
    <p>这里将接入账号登录功能。</p>
  </section>
</template>
```

RegisterView.vue：

```vue
<template>
  <section>
    <h2>注册</h2>
    <p>这里将接入账号注册功能。</p>
  </section>
</template>
```

TransactionsView.vue：

```vue
<template>
  <section>
    <h2>我的账单</h2>
    <p>这里将展示账单列表和月度统计。</p>
  </section>
</template>
```

将 src/router/index.ts 替换为：

```javascript
import { createRouter, createWebHistory } from 'vue-router'
import LoginView from '../views/LoginView.vue'
import RegisterView from '../views/RegisterView.vue'
import TransactionsView from '../views/TransactionsView.vue'

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes: [
    { path: '/', redirect: '/login' },
    { path: '/login', component: LoginView },
    { path: '/register', component: RegisterView },
    { path: '/transactions', component: TransactionsView },
    { path: '/:pathMatch(.*)*', redirect: '/login' },
  ],
})

export default router
```

src/main.ts 已生成并正确安装路由，可以保留；等价的精简写法为：

```javascript
import './assets/main.css'
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'

createApp(App).use(router).mount('#app')
```

将 src/assets/main.css 替换为：

```css
* { box-sizing: border-box; }
body {
  margin: 0;
```

RouterLink 负责发起页面导航，router 决定匹配哪个组件，RouterView 是该组件显示的位置。当前账单页只是占位，第三课才添加路由守卫。

### 5. Git 与后端镜像边界

确认 frontend/.gitignore 忽略 node_modules 和 dist，package-lock.json 保留提交。不要复制 node_modules 到服务器，也不要把密钥放进 VITE_ 变量，前端变量会被打包到浏览器文件中。

在仓库根目录 .dockerignore 末尾增加一行 frontend/。后端 Dockerfile 有 COPY . .，需要避免把前端工程及依赖复制到后端镜像。第七课单独处理前端构建和静态文件发布。

开发服务占用终端时，可以按 Ctrl+C 停止，或打开第二个终端在 frontend 目录执行构建。基础页面只做浏览器和构建检查，不为静态标题编写重复断言。第一课验收完成后才更新勾选项、提交 PR 并进入第二课。

## 后续接口约定

- 前端统一使用 /api 前缀；第二课在 Vite 开发代理中转发并去掉前缀，生产阶段由反向代理做相同映射。现有后端路由保持 /auth、/transactions、/statistics/monthly。
- 后端首页 / 返回 JSON；前端生产首页由反向代理提供，不把“后端首页能打开”当作前端发布完成。
- 登录与注册密码长度沿用学习者决定，分别为 1～128 和 7～128 字符。
- 首版 Token 仅内存保存，刷新重新登录；退出清空当前用户状态，不声称已经撤销 JWT。
- 金额显示与输入使用元，接口 amount_cents 使用整数分；以十进制字符串转换，不直接截断浮点结果。
- 列表按 ID 倒序，不返回总数；月度统计是全月口径，不随列表分类筛选变化。
