# 个人记账前端：开发清单

更新日期：2026-10-12。

目标：为现有 FastAPI 记账 API 开发 Vue 前端，使用户通过浏览器完成注册、登录、记账、查询、修改、删除和月度统计，并发布到已购买的服务器。

当前状态：前端业务通过 PR #5 合入 dev；部署配置位于 feat/frontend-deploy，提交 ab63244。前端镜像 1.0.0 已部署，学习者反馈通过 SSH 隧道完成上一课业务验收。当前收尾部署文档与 PR，备案仍在审批。此前 34 个前端测试和构建通过，本次 Compose 配置检查通过；远端 CI、双账号完整回归、容器重建持久化及备份恢复仍待核验。

本次收尾证据：5 个测试文件、34 个测试通过，包含账单页面 6 项交互测试。以下逐项保留待人工确认项，不把实现完成等同于线上验收完成。

技术方案：Vue 3、Composition API、script setup、TypeScript、Vite、Vue Router、原生 fetch；需要金额和请求逻辑测试时使用 Vitest。源码放在现有仓库 frontend/ 中，沿用现有后端。TypeScript 随功能学习，不因脚手架选择重新建工程。第一版不引入 SSR、Pinia、大型组件库或图表库；后续按具体需求决定。

本清单记录实际交付状态；逐课说明和第一课操作见《前端学习清单》。未执行的验收不勾选。

## 第二阶段：接口通信与登录状态（第二、三课）

- [x] 开发时使用本地测试后端，确定实际后端端口；配置 Vite /api 代理并去掉 /api 前缀，匹配现有后端路径。
- [x] 统一 fetch 请求，处理 JSON、204 无内容、HTTP 错误、网络失败、加载状态和重复提交。
- [x] 完成注册表单；用户名为 3～32 位小写字母、数字或下划线，密码为 7～128 个字符。
- [x] 完成登录、Bearer Token 发送与 /auth/me 验证；密码输入长度允许 1～128 个字符。
- [x] 首版 Token 保存在内存中，刷新页面后需要重新登录；前后端明确接受这个行为，不默认持久化 Token。
- [x] 受保护页面无登录态时转到登录页；路由守卫不能代替后端鉴权。
- [x] 区分登录失败 401 与已登录请求凭证失效 401；显示 409、422、429 和 Retry-After。
- [x] 登录提示沿用“用户名不存在，请先注册”和“密码错误”。
- [x] 退出时清空 Token 和当前用户数据；说明这不撤销服务器已签发的 JWT。
- [ ] 使用真实接口验收注册、登录、过期、错误提示和限流；密码与 Token 不打印或提交到 Git。
