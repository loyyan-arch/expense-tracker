# 个人记账后端：项目分阶段开发清单

目标：开发一个可以记录日常收支、按分类查询、统计月度收支，并部署到公网供自己使用的后端项目。

更新日期：2026-10-10。当前进入第六阶段：本地部署与 CI 已验收，接下来准备购买服务器并完成公网部署。服务器和域名尚未采购、配置。

勾选依据：当前代码核对及学习者逐课验收反馈。本次更新文档没有重新运行测试、访问 GitHub 检查或执行恢复。清单中的本地通过不代表服务器端已经通过。

第一版仅支持人民币，固定分类为餐饮、交通、购物、工资、其他。预算、报表导出、微信登录暂不纳入第一版。
